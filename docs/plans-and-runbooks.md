# Plans and Runbooks

Each active feature/release plan under `docs/plans/` names its runbook with `runbook:`. The runbook lists the plans it traces with `plans:`; the initial pair uses the same numbered filename. Plans hold current tasks and status; runbooks append dated findings, decisions, actions, and verification evidence. Keep both indexes current and reuse a relevant pair for follow-up work.
